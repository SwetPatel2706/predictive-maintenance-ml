# Predictive Maintenance ML Project - AI4I 2020

**Authors:** ML Course Project  
**Course:** Machine Learning Fundamentals

## Project Summary

This project builds predictive maintenance models using the **AI4I 2020 Predictive Maintenance Dataset** to predict whether a machine will experience a failure based on operating parameters. The model uses 6 key features: Product Type, Air Temperature, Process Temperature, Rotational Speed, Torque, and Tool Wear.

**Goal:** Predict `Machine_Failure` (0 = No failure, 1 = Failure) from machine operating parameters.

**Dataset:** AI4I 2020 Predictive Maintenance Dataset from UC Irvine ML Repository (id=601).

## Dataset Description

The AI4I 2020 dataset contains machine operating parameters collected from sensors. The task is binary classification to predict machine failure. Key characteristics:

- **Features:** Type (categorical), Air_Temperature, Process_Temperature, Rotational_Speed, Torque, Tool_Wear
- **Target:** Machine_Failure (0/1)
- **Class imbalance:** ~96.6% no-failure / ~3.4% failure
- **Leakage columns excluded:** TWF, HDF, PWF, OSF, RNF (directly related to target)

## Setup Instructions

### 1. Create and activate virtual environment

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**Windows (cmd.exe):**
```cmd
python -m venv .venv
.venv\Scripts\activate.bat
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Place the dataset
Place the `ai4i2020.csv` file in `data/raw/`.

### How to run

**Single command - full pipeline:**
```bash
python -m src.run_pipeline
```

This runs the complete chain: load → clean → split → build preprocessor → train 3 models → evaluate → generate all plots → tune Random Forest → save all results/model/figures.

**Individual modules (standalone mode):**
Each module can be run independently using the `python -m src.<module>` syntax (works identically on Mac/Windows):

- `python -m src.data.preprocessing` - Data loading, cleaning, split
- `python -m src.models.train` - Train baseline models
- `python -m src.models.evaluate` - Evaluate models and generate plots
- `python -m src.models.tune` - Tune Random Forest with GridSearchCV

All run commands use `python -m src.<module>` syntax (not raw relative file paths) so commands are identical cross-platform.

## Limitations

1. **Class imbalance trade-off:** The dataset is ~96.6% no-failure / ~3.4% failure. Recall is the weaker metric due to class imbalance. Threshold tuning, SMOTE, or cost-sensitive learning are valid future improvements (mentioned only, not implemented).

2. **Hyperparameter tuning scope:** GridSearchCV tuning was deliberately applied only to Random Forest as the strongest baseline, not all three models. Logistic Regression and Decision Tree are baseline comparisons only.

3. **Leakage columns:** `TWF`, `HDF`, `PWF`, `OSF`, `RNF` columns must NOT be used as input features as they are directly related to the target and would leak information.

4. **No SMOTE or resampling:** Imbalance handling is limited to `class_weight='balanced'` in models. Additional resampling techniques are not implemented.
